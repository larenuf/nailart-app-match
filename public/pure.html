Saf HTML ve CSS ile UI Bileşenleri

Bu Sayfa Nedir?

Bu sayfada, Nail Art Match uygulamasının UI bileşenlerini saf HTML, CSS ve JavaScript ile oluşturulmuş bir versiyonunu görebilirsiniz. Herhangi bir framework veya kütüphane kullanılmadan tasarlanmıştır.

Bu sayfa çalışıyorsa, sunucu tarafında statik dosyaların doğru şekilde servis edildiği anlamına gelir.
